آخر إشارة — الأمانة

تشغيل المشروع:
1. فكّي ضغط الملف.
2. افتحي index.html بمتصفح على الكمبيوتر، واتركي مجلد images وملف photos.js بجانبه.
3. عند النشر، ارفعي محتويات المشروع كلها إلى جذر المستودع، وليس ملف ZIP نفسه.
4. افتحي رابط GitHub Pages المنشور للعب من الهاتف.

إضافة صورة جديدة:
1. ضعي الصورة داخل images/photos.
2. سمّيها باسم بسيط دون مسافات، مثل new-photo.jpg.
3. افتحي ملف photos.js بمحرر نصوص.
4. أضيفي العنصر التالي داخل القائمة، قبل آخر قوس مربع ]، مع فاصلة بين العناصر:

  {
    "title": "عنوان الصورة الجديدة",
    "src": "images/photos/new-photo.jpg"
  }

5. احفظي الملف وارفعي photos.js والصورة الجديدة إلى المستودع.
ستظهر الصورة في تطبيق الصور، مع التكبير والمفضلة والتنقل.

انتبهي إلى تطابق اسم الملف والامتداد وحالة الحروف بالضبط.
مثال: new-photo.jpg مختلف عن New-Photo.JPG.
احتفظي بصورة الرصيف وبياناتها لأنها دليل ضمن الألغاز.
يمكنك حذف الصور الشخصية الأخرى من القائمة دون التأثير على الحل.

ترتيب المجلدات:
index.html : واجهة اللعبة ومنطقها.
photos.js : قائمة صور تطبيق الصور؛ هذا الملف هو الذي تعدلينه لإضافة الصور.
images/photos : الصور الشخصية وصورة دليل الرصيف.
images/icons : صور أيقونات التطبيقات.
images/wallpaper.jpg : خلفية الهاتف.

لا ترسلي index.html وحده؛ أرسلي مجلد المشروع كاملًا أو ملف ZIP.
الصور أصبحت ملفات منفصلة، لذلك لم يعد HTML نسخة مستقلة عن بقية الملفات.
